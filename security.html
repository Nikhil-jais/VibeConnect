Authentication

VibeConnect uses Supabase Authentication instead of storing account passwords inside your website code.

  • Secure sign-in sessions
  • Email/password authentication
  • Authenticated user IDs
🚧

Row Level Security

RLS policies restrict database operations according to the currently authenticated user.

  • Users access their own private data
  • Users cannot edit another account
  • Database policies enforce permissions
📦

Frontend Safety

Public frontend code should never contain privileged Supabase credentials.

  • Never expose service-role keys
  • Use the publishable/anon key
  • Keep database rules enabled
🧹

Safe User Input

User-generated content should be handled carefully before being displayed.

  • Validate form input
  • Escape displayed text
  • Use database policies for authorization
